Entry by **@wantorieta15** (Akun 2) for the make.fun bounty
**One-Star Review of Something Essential** — a deadpan one-star review,
in a single line, of an everyday essential everyone relies on.

## Entry

> One star. The duvet is exactly wide enough for one person and a half, and every night I discover I am the half.

The duvet is the essential here: it never quite covers two people, and
every night the same person ends up being the half that goes without.
One concrete nightly scene, one twist in the final words, no wink, no
exclamation — a genuine complaint filed against something that cannot
be fixed.

## How it works

`main.py` (pure Python stdlib, no dependencies, no network) writes the
frozen one-line review to `entry.txt` in the output directory
(`MAKEFUN_OUTPUT_DIR`, default `/output`), exactly 111 bytes with no
trailing newline.

Run it:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/one-star-review-a2-verify python3 main.py
```
